# LocalHub : 구미·경북 지역 정보 공유 커뮤니티
구미와 경북의 다양한 로컬 데이터를 직관적인 UI로 제공하는 공공데이터 기반 1인 익명 지역 커뮤니티 및 AI 가이드 플랫폼입니다.

---

## 1. 프로젝트 설명

### 기획 배경 및 동기
* **공공데이터 활용성 극대화**: 여러 기관에 분산되어 존재하는 구미/경북 지역의 유용한 공공데이터(관광지, 맛집, 축제, 숙박)를 정제하여 사용자가 한눈에 파악할 수 있는 통합 뷰를 제공하고자 기획했습니다.
* **익명성 보장을 통한 자유로운 커뮤니티**: 복잡한 회원가입 절차와 개인정보 수집 없이, 브라우저 로컬 저장소(LocalStorage)를 활용해 누구나 부담 없이 지역 소식을 공유할 수 있는 공간을 설계했습니다[cite: 1].

### 해결하고자 한 문제
* **서버 유지비 최소화 및 로딩 속도 개선**: 별도의 백엔드 서버나 DB 없이 동작하는 프론트엔드 단일 구조(정적 SPA)로 구축하여, 서버 통신 지연을 없애고 렌더링 속도를 향상시켰습니다[cite: 1].
* **정보 탐색의 한계 극복**: 단순한 텍스트 기반 검색 환경을 보완하기 위해, 탑재된 로컬 데이터를 인지한 OpenAI GPT 기반 챗봇이 자연어 대화를 통해 사용자의 취향에 맞는 장소를 실시간으로 추천하도록 구현했습니다[cite: 1].

### 프로젝트를 통한 학습 내용
* **컴포넌트 설계 및 데이터 흐름 파악**: 초기 App.vue 단일 파일 구조에서 겪었던 코드 복잡성과 렌더링 지연 문제를 컴포넌트 단위(7개 파일)로 세분화하여 해결했습니다. 이 과정에서 Vue 3의 Props와 Emit을 활용한 부모-자식 간 데이터 흐름을 깊이 이해하게 되었습니다[cite: 1].
* **클라이언트 사이드 데이터 관리**: 외부 서버의 도움 없이 브라우저 내 LocalStorage만을 사용하여 데이터의 추가, 조회, 수정, 삭제(CRUD)를 안정적으로 처리하는 흐름을 익혔습니다[cite: 1].

## 3. 주요 핵심 기능

* **정돈된 레이아웃 디자인**: 구미의 자연경관을 메인 비주얼로 활용한 대형 배너와 그 위에 자연스럽게 얹어진 통합 검색창을 구성했습니다. 전반적인 톤앤매너는 깔끔한 화이트와 슬레이트 그레이 컬러로 차분하게 통일했습니다.
* **공공데이터 카드 디렉토리**: public/all-data.json 경로의 데이터를 가공하여 관광지, 맛집, 축제, 숙박 리스트를 상세 분류하고, 실제 사진 이미지와 함께 주소를 깔끔한 카드 형태로 렌더링합니다[cite: 1].
* **비밀번호 기반 익명 게시판 (CRUD)**: 회원가입 절차 없이 글을 작성할 수 있으며, 수정 및 삭제 요청 시 본인이 작성한 4자리 숫자 비밀번호의 일치 여부를 프론트엔드 단축 로직으로 검증합니다[cite: 1].
* **자연어 처리 AI 가이드**: 화면 우측 하단에 상시 배치된 슬라이드 형태의 챗봇 대화창을 통해 구미/경북의 주요 명소(금오산, 에코랜드 등)와 맛집에 대한 정보를 제공합니다[cite: 1].

## 4. 배포 및 실행 방법

본 프로젝트는 GitHub 저장소와 Netlify 서비스를 연동하여 지속적 배포(CD) 환경을 구축했습니다[cite: 1]. 

### 1) 실시간 배포 사이트 주소
* **배포 URL**: [https://여기에_본인의_넷리파이_배포_링크_넣기.netlify.app](https://여기에_본인의_넷리파이_배포_링크_넣기.netlify.app)[cite: 1]

### 2) Netlify 배포 환경 변수 설정 방법 (중요)
OpenAI API 호출을 위해 빌드 환경에 API 키를 등록해 주어야 합니다. 깃허브에는 .env 파일이 업로드되지 않으므로 아래의 과정을 거쳐 설정합니다[cite: 1].
1. Netlify 콘솔의 해당 프로젝트 대시보드 진입
2. Site configuration -> Environment variables 메뉴로 이동
3. [Add a variable] 버튼 클릭 후 아래의 값을 입력하고 저장
   * Key: `VITE_OPENAI_API_KEY`
   * Value: (본인의 OpenAI API 실물 키 값 입력)[cite: 1]
4. Deploys 메뉴에서 Trigger deploy -> Clear cache and deploy site를 실행하여 재배포 완료

### 3) 로컬 실행 방법 (테스트 목적)
로컬에서 프로젝트를 복제하여 직접 구동해 보려면 아래의 단계를 따릅니다. (Node.js LTS 버전 필요)

```bash
# 1. 저장소 복제 및 폴더 이동
git clone [https://github.com/사용자_깃허브_ID/localhub-gumi.git](https://github.com/사용자_깃허브_ID/localhub-gumi.git)
cd localhub-gumi

# 2. 패키지 설치 및 로컬 .env 설정
npm install
echo "VITE_OPENAI_API_KEY=your_actual_key_here" > .env

# 3. 개발 서버 실행
npm run dev
